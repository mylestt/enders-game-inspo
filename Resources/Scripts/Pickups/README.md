# Pickup scripts

Put pickup-specific behavior here. Scene counterparts belong in
`Resources/Objects/Pickups/`.

Examples:

- `speed_boost.gd` for a temporary movement-speed pickup.
- `jump_boost.gd` for a temporary launch-force pickup.
- `pickup_respawner.gd` for shared respawn behavior.

The legacy shared `Resources/Scripts/PowerUp.cs` base remains at its existing
path. See `docs/PROJECT_STRUCTURE.md` for the full convention.
