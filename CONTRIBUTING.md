# Contributing

Thanks for helping build this game! Please read this before contributing — it
keeps ownership clean so the project doesn't get tangled later.

## This project is proprietary

It is **not** open source (see [LICENSE](LICENSE)). The code and assets belong to
the project owner. You've been given repository access so you can help build
*this* game — not to reuse the code or assets elsewhere.

## By contributing, you agree that

- Your contributions (code, art, audio, design, etc.) become part of the project
  and are **assigned to the project owner** (Myles Thornell Timmer), unless you
  and the owner have a separate written agreement.
- You will **not** reuse this project's code or assets in your own or anyone
  else's separate project without the owner's written permission.
- You keep **credit** for your work — your name in the commit history and credits
  stands — but not ownership/IP rights in the game.

If you're not comfortable with this, talk to the owner *before* contributing.

## Access

Repository access is for contributing to this project only. Don't redistribute
the source or share access without the owner's OK.

## Workflow (quick)

- Branch off `main`, open a pull request, and let the owner review before merging.
- Keep commits focused and described.
- The deploy/build steps and project conventions are in
  [`CLAUDE.md`](CLAUDE.md), [`DEPLOY.md`](DEPLOY.md), and `PROJECT_OVERVIEW.md`.
